# Max-Quordlepleen

Team 2059 "The Hitchikers" 2024 competition robot, reimagined for demonstration purposes.

## Basic Controls
| Button     | Command                                                                       |
|------------|-------------------------------------------------------------------------------|
| WINDOW     | Reset Gyro Heading (RoboRIO is Front)                                         |
| MENU       | Switch between Field-Relative and Robot-Relative modes (Click ONCE to switch) |
| R Trigger  | Spin-up Shooter Motor                                                         |
| R Bumper   | Spin Indexer Motor (Shoot Note)                                               |
| L Joystick | X-Axis: Strafe, Y-Axis: Fwd/Back                                              |
| R Joystick | X-Axis: Rotation                                                              |
| A          | Intake Note Sequence                                                          |
| B          | Outtake Note (Release Note from Collector)                                    |
| X          | Collector Out Pos |
| Y | Collector In Pos |
